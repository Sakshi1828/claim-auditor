Less clutter: what we moved, folded away and put in tabs

How each screen is organised now

Every screen now follows the same order: 1. the main point at the top, 2. the key numbers in the middle, 3. the detail behind a click.

Step 1 · Load a report

MovedThe report box and the big “Check every claim” button are now at the top, so the first thing you see is what to do.
CollapsedYour name, your role, the data release folder and the AI tick box are now inside “Settings” (click to open). A short line explains when to change the data folder.
UnchangedPractice report, Upload a file, and Open a sealed envelope stay exactly where they were.

Result · Key takeaway

AddedA “Key takeaway” heading above the summary. It only labels the summary that was already there; no new findings.
RestyledThe result counts (contradicted, insufficient, supported, not a claim) now look like small number cards.
Unchanged“Explain it in plain words” and “Glossary” still open the plain-language box.

Step 2 · Review each claim

CollapsedThe key to the coloured labels (From the data / Interpretation / From the report) is now behind “What do the coloured labels mean?”.
TabbedEach claim's details are now in 3 tabs instead of one long page: “The numbers”, “What to do”, “How it was checked”. The claim itself, its plain-words line and the one-line summary stay on top.
UnchangedConfirm, Override, Undo and Next claim are always visible under the tabs. Filters and the Program lead / Reviewer / Researcher switch work as before.

Step 3 · What happens next

MovedYour decision and the Export button now come right after the tool's suggestion, so the main action is easy to find.
TabbedThe supporting information is in 3 tabs: “Steps to fix”, “What the check can't tell you”, “Corrected report”.
ShortenedLong lists show the first 3 items and a “Show all (N)” button. Nothing is removed.

Easier to read everywhere

  • Text lines stop at about 70 letters wide, so your eyes don't travel too far.
  • A bit more space between lines in longer text.
  • Each section has one icon, one heading and one short helper line.
  • Tabs can also be used with the keyboard (left and right arrow keys).

How we checked that nothing was lost

  1. Before changing anything, we recorded all 554 pieces of text the page shows (two test reports, every claim, every detail level).
  2. After the change, we opened every tab, fold-out and “Show all”, and collected the text again.
  3. Result: 0 missing. The only differences are the new headings and helper lines, and the run time (“checked in 0.25 s”), which is different every run.
  4. We clicked every button in order: practice report, check, plain words, glossary, filters, tabs, copy wording, confirm, override, undo, detail levels, role, decision, export. All worked; the export said “valid”.
  5. Our automatic comparison against the original page: no value, button, download or label removed or edited.

Nothing was skipped

Every change was a safe rearrangement of what was already there, so nothing had to be skipped.
