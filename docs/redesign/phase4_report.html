Why we did not add a chart add-on

The app had no chart add-on; it draws its own small charts. Adding one (such as Chart.js) would mean downloading it from the internet each time, which breaks the 'works offline, nothing leaves this computer' promise, or changing how the server sends files, which our rules don't allow. So we upgraded the app's own charts instead.

Over-time charts: the app shows no values over time, so there is nothing to draw as a line chart. Error bars: the app shows an allowed margin, not confidence intervals; that margin is drawn as a shaded band.

Colours, screen readers and phones

  • Chart colours come from a 6-colour set that stays distinguishable for colour-blind readers.
  • Every chart has a spoken summary for screen readers, and every table has proper column headings.
  • The bars grow in gently; the motion switches off for anyone who prefers less motion.
  • On a phone-sized screen the charts fit without sideways scrolling.
