Showing the evidence, limits and next step clearly

We made the sources, the status of each result, the limitations and the recommended next step easy to see. Everything shown already existed in the app: no source, confidence level, limitation or recommendation was invented.

What we surfaced, and where

1. Sources (claim details, 'How it was checked' tab)

SurfacedEach data file a result was computed from is now shown as a small source card: file name, type (data table or manifest), release, and the file's fingerprint.
SurfacedA badge in the claim header shows how many sources it used, for example '1 source'.
SurfacedIn the summary's evidence list, each claim has 'See evidence (N sources)', which opens that claim straight on its evidence tab.
Not shownTitles, years and web links: the app has none for its data files, so none were added.

2. Status badges (claim header and evidence list)

Surfaced'Conflicting findings' where the result is Contradicted.
Surfaced'Limited data' where the result says data is missing (for example no RNA file); 'Uncertain' for other Insufficient evidence.
Surfaced'Strong evidence' only where the result is Supported and the tool's own confidence is high and not borderline; otherwise 'Uncertain'.
SurfacedA small 3-step meter beside the tool's existing confidence (high, medium, low).

3. Limitations, missing data and conflicts

SurfacedEach result's own limitation text now appears as a 'Limitation' box at the top of 'What to do'.
RestyledThe existing 'What the data shows instead' (conflict) and 'Data that would be needed' (missing data) boxes have a clear coloured edge.

4. Recommended next step (end of Step 3)

SurfacedA conclusion card: the tool's suggested decision, its reason, the first steps to fix, the key limitations, and who should also review (taken from 'Also needs review by').
UnchangedThe decision itself is still made by a person; the card only repeats the existing plan.

5. Disclaimer

RestyledThe existing 'research use only' line at the bottom is now a calm grey note with an info icon, and the 'Research use only' note in the top bar has a soft green edge. No new disclaimer was written.
