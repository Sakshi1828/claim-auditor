Why is each sentence said? Click it to see

Every checked sentence can now be clicked to see exactly why it is said: the data it was checked against and the checker's reason. Only links the app already had are shown; nothing was guessed, and every sentence keeps its exact words.

What we found, and what we built

Step 1. What links already existed (checked before building)

FoundFor every sentence, the checker already records which data files it used, which fields in them, and its reason. For reports that label their claims, it also records the evidence the report itself cites.
FoundPractice report: 3 of 6 sentences linked to data files. Demo report: 13 of 18. Labelled synthetic report: 8 of 8 linked to the report's own cited evidence.
Not linkedOpinions, recommendations, background lines and claims the tool could not measure have no source. They now say 'No source linked for this statement.'
Not doneNo links were made up or found by matching words. Only the links above are used.

Step 2. Read the report with its sources (Step 2 of the app)

AddedA fold-out 'Read the report with its sources' shows every checked sentence, word for word. Clicking a sentence, or pressing Enter on it, opens a side panel titled 'Why this is said' (a bottom sheet on phones).
AddedThe panel shows the sentence, its result and status, the number of sources, the checker's reason, the report's cited evidence if any, the data files and fields used, and a button to open the full source and calculation.
UnchangedThe existing list of sentences on the left still works exactly as before: clicking one opens its details.

Groups and highlighting

AddedSentences that rest on the same data files form a group. With 'Show highlights' on, each group gets a soft colour and a small number, so colour is never the only clue. A legend lists the groups.
AddedClicking a sentence highlights its whole group and dims the rest. Highlights are off by default, so the normal view stays clean.

Reverse: from a source to its sentences

AddedClicking a group in the legend, or a data file in the panel, highlights every sentence that file supports.

Keyboard and screen readers

AddedEvery sentence can be reached with Tab; Enter opens the panel; Escape closes it and returns you to the sentence. Each sentence and the panel have spoken labels.

How we tested it

  1. Every sentence in the new view has exactly the same words as the report (checked one by one).
  2. Clicking a sentence opens 'Why this is said' with its real sources; a sentence with no source says 'No source linked for this statement.'
  3. Group highlight, dimming of the other sentences, the legend, and clicking a data file to highlight every sentence it supports all worked.
  4. 'Show highlights' is off at first and switches on and off.
  5. With real key presses: Escape closes the panel and returns to the sentence; Enter opens it again.
  6. On a phone-sized screen the panel opens as a full-width bottom sheet, with nothing spilling off the side.
  7. The original sentence list, the review buttons and Export still work (export said 'valid'); the results never changed.
  8. All 574 pieces of text from before are still on the page; the comparison against the original page found nothing removed or edited; all 5 test packs pass.

Which files changed

web/index.htmlThe new view, the panel and their styles. Nothing that checks claims, saves results or talks to the server was touched.
tools/ui_baseline.pyNow also allows the new view's boxes and the highlight switch.
